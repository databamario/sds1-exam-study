L1-MC-014: stop using a literal that looks like a symbol

The previous option (b) used `x <- 3.14` to illustrate the numeric type. The
literal is in p.52's recap table as the numeric example, so the option is
technically correct, but `3.14` is π in disguise. A student can briefly wonder
whether the test is about R or about constants they half-remember, and arrive
at the right answer for the wrong reason. The literal in the option is now
`2.5`, which is numeric without standing for anything else.

The stem is also sharper. The old wording was "Which of the following statements
about R data types are TRUE?", which describes an abstract topic. The new
wording is "Consider these R assignments. Without running the code, which of
the descriptions are TRUE?", which puts the assignment-to-type mechanic on the
page. The question always tested what each assignment produced; now the stem
says so.

Page and key unchanged. p.52 already supported both keyed options and now
also names 2.5 as a numeric example would, by absence, since "any number with a
decimal point" is what p.52's recap row actually says.
